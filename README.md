# Hospital-Emergency-Room-Analytics-Dashboard
A Power BI project analyzing Emergency Room performance, patient demographics, operational efficiency, and referral patterns using real‑world healthcare data.

📌 Project Overview

  This end‑to‑end analytics solution delivers a comprehensive view of ER operations through four interactive dashboards—Monthly View, Consolidated View, Patient Details, and Key Takeaways. The report enables hospital leadership to monitor patient flow, wait times, satisfaction, demographics, referrals, and admission trends for data‑driven decision‑making.

🎯 Objectives

  Track ER patient volume and daily/monthly trends

  Analyze wait times and satisfaction scores

  Evaluate admission vs. non‑admission patterns

  Identify peak days and hours for staffing optimization

  Study demographic distribution (age, gender, race)

  Monitor department referral trends

  Provide actionable insights to improve ER operations

📊 Dashboards Included

   Department referrals

4. Key Takeaways

📈 Key Insights:

  Average ER wait time: ~35 minutes

  Nearly equal split between admitted vs. non‑admitted patients

  Peak days: Monday, Saturday, Tuesday

  Peak hours: 11 AM, 1 PM, 7 PM, 11 PM

  Most referrals: General Practice & Orthopedics

  Largest demographic groups: Adults (30–39), Young Adults (20–29)
